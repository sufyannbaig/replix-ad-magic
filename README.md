# Replix Ad Studio

Build a web app called "Replix AI — Ad Studio": a redesigned ad-creative generation tool for Shopify sellers. This is a client-facing DEMO PROTOTYPE — prioritize a polished, realistic UI running on rich mock data over real backend logic. Use React + TypeScript + Tailwind + shadcn/ui. Do not build real authentication or payments — a logged-in state is enough.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://replix-ad-magic.lovable.app
